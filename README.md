# めだか日和 — Habit Aquarium

食事と水分の記録をメダカのお世話につなげる、静的Webゲーム。

- 朝・昼・夜・間食ごとに、たんぱく質・脂質・炭水化物を1〜10で記録すると給餌します。
- 飲んだ水の量をmLで記録すると水換えします。水分量のノルマはありません。
- 水のきれいさは最後の水換えからゆっくり変化します。メダカが死ぬことはありません。
- 日付別の履歴、記録取消、JSONの書き出しに対応します。
- データは端末・ブラウザーごとのlocalStorageに保存されます。同期はありません。ブラウザーデータ削除で記録が失われるため、必要に応じて書き出してください。JSONの再読み込みは未対応です。
- 10段階は主観的な量で、栄養素のグラム換算や医学的な評価をしません。

## ローカルで開く

このディレクトリーで `python -m http.server 8000` を実行し、http://localhost:8000 を開きます。ビルドやnpmパッケージは不要です。Google Fontsが使えない場合もシステムフォントで動作します。

## GitHub Pages

GitHubリポジトリーの Settings → Pages → Source を **GitHub Actions** にします。`main` へのpushで `.github/workflows/pages.yml` が実行され、HTML・CSS・JavaScriptの3ファイルだけを公開します。健康記録はリポジトリーに含まれず、ブラウザーに保存されます。
