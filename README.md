# めだか日和

AndroidのChromeを主な対象にした、メダカと健康習慣を育てる静的Webゲーム。

## 体験

- スマホを基準にした1列の画面。PCでも最大480pxの同じレイアウトです。
- 「水槽」「にっき」の2画面。食事・水分の入力は下から開きます。
- 食事のたんぱく質・脂質・炭水化物を主観的な1〜10で記録。グラム換算や栄養評価は行いません。
- 保存後は水槽へ戻り、メダカがえさに集まります。水分の記録では水換え、泡、きらめきが発生します。
- 最初の記録で1日1つ「お世話の花」が咲き、カレンダーに残ります。途切れても過去の花は失われません。日付の全記録を取り消した場合はその日の花も取り消されます。
- メダカの専用イラスト、約30fpsのCanvas描画。非表示時は描画を止め、動きを減らす設定にも対応します。

## 保存

既存版と同じlocalStorageキー `medaka-biyori-v1` を使うため、同じ端末・Chrome・URLで以前の記録を引き継ぎます。記録はGitHubに送信しません。ブラウザーデータ削除・端末故障等に備え、設定からJSONをバックアップできます。復元はID単位で重複を除いて追加し、今の記録を保持します。端末間の自動同期はありません。Chromeの保持許可はブラウザーが判断します。

初回オンラインで読み込んだ後はService Workerのキャッシュでオフラインでも起動・記録できます。Chromeのメニューからホーム画面に追加できます。キャッシュ更新時は `sw.js` のバージョンを更新してください。Google Fontsは取得できない場合、システムフォントで表示します。

## 開発・公開

- `python -m http.server 8000` でローカル起動。
- `node --test core.test.cjs` でデータ互換性・入力検証・復元・日付を検証。
- GitHub Pages: `main` へのpushでActionsが静的ファイルを公開。
- 画像 `assets/medaka.png` はこのゲーム用に生成。`assets/icon.svg` はアプリアイコン。

## 確認範囲

390px相当のブラウザー表示、食事/水分入力、入力範囲エラー、既存記録の引継ぎ、日記、通信停止時の起動・保存・再読み込みを検証。Android実機でのインストール、OSの省電力・ストレージ管理挙動は未検証です。
